## 移动软件开发课程作业

| 实验 | 内容 | 仓库 |
| --- | --- | --- |
| 实验一 | Android 开发基础（环境、Activity 生命周期、Toast/Log） | [Lab1-HelloAndroid](https://github.com/kkkiriko6767/Lab1-HelloAndroid) |
| 实验二 | Android 界面布局（线性、表格、约束布局） | [Lab2-LayoutLab](https://github.com/kkkiriko6767/Lab2-LayoutLab) |
| 实验三 | Android 界面组件（ListView、Dialog、Menu、ActionMode、RecyclerView） | [Lab3-ComponentLab](https://github.com/kkkiriko6767/Lab3-ComponentLab) |
| 期中实验 | NotePad 记事本应用（时间戳、搜索、分类颜色、置顶、分享） | [Midterm-NotePad](https://github.com/kkkiriko6767/Midterm-NotePad) |

## 每个仓库里有什么

- `app/`：完整工程源码，可直接用 Android Studio 打开并运行
- `docs/`：对应的实验报告（Word 文档）
- `README.md`：实验内容、主要功能点、运行方法
- `.gitignore`：按 Android 官方模板配置，不包含 build/、.idea/、local.properties 等本机文件

环境：Android Gradle Plugin 8.5.2 / Gradle 8.7 / compileSdk 34 / minSdk 24 / JDK 17。
